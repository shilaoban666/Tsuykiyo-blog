# 公众号文章导入

把「石哥说编程」的文章放进这个文件夹，我会批量导入博客。

## 方式 A：公开文章链接（最省事）

1. 在微信里打开文章，右上角「…」→「复制链接」
2. 把链接逐行贴到 `links.txt`，一行一个
3. 如果知道发布时间，可以写成：

```text
https://mp.weixin.qq.com/s/xxxxxxxx | 2025-03-21
```

我会先测试能否抓到正文和图片；能抓就批量导入。

## 方式 B：导出 HTML / Word

微信公众号后台没有官方批量导出，但可以：

- 浏览器打开文章 → 右键「另存为」→ 网页（完整）
- 或复制正文到 Word，保存为 `.docx`
- 把文件放进 `files/`，文件名建议用文章标题

目录结构：

```text
wechat-import/
├─ links.txt
├─ files/
│  ├─ 2025-03-21-文章标题.html
│  └─ 2025-03-28-文章标题.docx
└─ index.csv
```

## 方式 C：手动 Markdown

如果前两种都不方便，直接把正文按 Markdown 放进 `files/*.md`，标题用一级标题即可。

## 阅读量和评论

微信公众号的阅读量、评论数**不对外公开**，只有账号后台能看到，所以不能像 CSDN 一样自动抓取。

可选：

- 不显示互动数字，只保留「公众号原文」链接
- 你从后台导出真实数据（截图/CSV），我按真实数字写入，并标注「公众号阅读」
- 不伪造数字

## 我会怎么导入

- 分类：`公众号文章`
- 来源：`石哥说编程`
- 保留原文链接、发布时间
- 正文图片下载到本地并压缩为 WebP
